# GameMods - Платформа модов для игр

Современный и красивый сайт для публикации и скачивания модов к играм.

## 🚀 Особенности

- **Современный дизайн** - темная тема с градиентами и анимациями
- **Адаптивная верстка** - работает на всех устройствах
- **Иконки Font Awesome** - богатая библиотека иконок
- **Плавные анимации** - интерактивный пользовательский интерфейс
- **Оптимизировано для FastPanel** - готово к развертыванию

## 📁 Структура проекта

```
mods-site/
├── index.html          # Главная страница
├── database.sql        # SQL дамп базы данных MySQL 8
├── css/
│   └── style.css       # Основные стили
├── js/
│   └── main.js         # JavaScript функционал
├── images/             # Изображения
└── uploads/            # Загруженные файлы модов
```

## 🗄️ База данных MySQL 8

База данных включает следующие таблицы:

- **users** - пользователи (администраторы, модераторы, пользователи)
- **games** - игры
- **categories** - категории модов
- **mods** - моды
- **mod_images** - изображения модов
- **reviews** - отзывы и рейтинги
- **downloads** - история скачиваний
- **tags** - теги
- **mod_tags** - связь модов и тегов

### Установка базы данных

```bash
# Подключитесь к MySQL
mysql -u root -p

# Импортируйте базу данных
source /path/to/mods-site/database.sql
```

Или через FastPanel:
1. Откройте панель управления FastPanel
2. Перейдите в раздел "Базы данных"
3. Создайте новую базу данных `game_mods_db`
4. Импортируйте файл `database.sql`

## 🔧 Настройка для FastPanel

### 1. Создайте сайт в FastPanel
```
Домен: yourdomain.com
Корневая папка: /var/www/yourdomain/data/www/yourdomain.com
```

### 2. Скопируйте файлы
```bash
cp -r /workspace/mods-site/* /var/www/yourdomain/data/www/yourdomain.com/
```

### 3. Настройте базу данных
- Создайте пользователя БД в FastPanel
- Обновите параметры подключения в PHP файлах (будут добавлены)

### 4. Установите права доступа
```bash
chown -R www-data:www-data /var/www/yourdomain/data/www/yourdomain.com/
chmod -R 755 /var/www/yourdomain/data/www/yourdomain.com/
chmod -R 777 /var/www/yourdomain/data/www/yourdomain.com/uploads/
```

### 5. Настройте PHP (опционально)
Для работы с базой данных потребуется PHP бэкенд. Рекомендуемая версия: PHP 8.1+
